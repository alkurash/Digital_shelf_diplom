	ЗАКЛЮЧЕНИЕ
}

\subtitlespace

{\gostFont
	\par \redline В рамках данного дипломного проекта было разработано программное обеспечение для автоматизированной проверки выкладки товаров на торговых полках, включающее нейросетевой модуль на основе архитектуры YOLOv8 и Telegram-бот для полевых сотрудников компании «Санта Импэкс».

    \par \redline В процессе выполнения дипломного проекта были решены следующие задачи:
	
	\begin{itemize}[leftmargin=2.15cm, labelwidth=0.65cm, labelsep=0.0cm] 
		
		\item[\theitemcntr.] Проведён анализ предметной области мерчендайзинга и требований компании «Санта Импэкс» к контролю соответствия выкладки товаров планограммам.
		\addtocounter{itemcntr}{1}
		
		\item[\theitemcntr.] Выполнен обзор существующих аналогов систем компьютерного зрения для розничной торговли и обоснован выбор архитектуры YOLOv8 в качестве базовой модели обнаружения объектов.
		\addtocounter{itemcntr}{1}
		
		\item[\theitemcntr.] Сформирован и размечен набор данных для обучения модели с использованием платформы Roboflow; применены методы аугментации для повышения обобщающей способности нейронной сети.
		\addtocounter{itemcntr}{1}
		
		\item[\theitemcntr.] Выполнено обучение и дообучение модели YOLOv8 на собственном датасете; проведена оценка качества по метрикам mAP, Precision и Recall.
		\addtocounter{itemcntr}{1}
		
		\item[\theitemcntr.] Разработан Telegram-бот для полевых сотрудников, обеспечивающий приём фотографий торговых полок, их передачу на сервер анализа и возврат результатов проверки без установки дополнительного программного обеспечения.
		\addtocounter{itemcntr}{1}
		
		\item[\theitemcntr.] Спроектирована и реализована серверная часть системы, включающая модуль инференса нейронной сети на основе ONNX Runtime и базу данных для хранения результатов проверок.
		\addtocounter{itemcntr}{1}
		
		\item[\theitemcntr.] Реализован алгоритм сопоставления обнаруженных товарных позиций с эталонной планограммой и формирования отчёта об отклонениях.
		\addtocounter{itemcntr}{1}
		
		\item[\theitemcntr.] Проведено тестирование всех компонентов системы: нейросетевого модуля, Telegram-бота и серверной логики.
		\addtocounter{itemcntr}{1}

		\setcounter{itemcntr}{1}
	\end{itemize} 

	\par \redline Разработанное программное обеспечение удовлетворяет всем поставленным требованиям, а именно:
	
	\begin{itemize}[leftmargin=2.15cm, labelwidth=0.65cm, labelsep=0.0cm] 
		
		\item[\theitemcntr.] Автоматическое обнаружение товарных позиций на фотографиях торговых полок в режиме реального времени.
		\addtocounter{itemcntr}{1}
		
		\item[\theitemcntr.] Сравнение фактической выкладки с эталонной планограммой и выявление несоответствий.
		\addtocounter{itemcntr}{1}
		
		\item[\theitemcntr.] Доступность системы через мессенджер Telegram без необходимости установки дополнительного ПО на устройство мерчендайзера.
		\addtocounter{itemcntr}{1}
		
		\item[\theitemcntr.] Хранение истории проверок и формирование отчётности по торговым точкам.
		\addtocounter{itemcntr}{1}
		
		\item[\theitemcntr.] Устойчивость системы к сбоям и корректная обработка ошибочных входных данных.
		\addtocounter{itemcntr}{1}
		
		\setcounter{itemcntr}{1}
	\end{itemize}  
	  
	\par \redline Проведённое тестирование подтвердило корректность работы всех функциональных модулей и соответствие результатов распознавания заданным показателям качества.

	\par \redline Для разработанного программного обеспечения был осуществлён расчёт экономической эффективности, определена полная себестоимость проекта, отпускная цена и чистая прибыль разработчика от реализации программного продукта.
