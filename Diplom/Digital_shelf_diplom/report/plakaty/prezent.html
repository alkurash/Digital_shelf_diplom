Функция потерь YOLOv8

Суммарная функция потерь при обучении включает три составляющих:

ℒ = λbox·ℒbox + λcls·ℒcls + λdfl·ℒdfl

• ℒbox — CIoU-потеря регрессии ограничивающего прямоугольника. Учитывает площадь пересечения, расстояние между центрами и соотношение сторон.

• ℒcls — Binary Cross-Entropy классификации для каждого из 15 классов SKU

• ℒdfl — Distribution Focal Loss для точного уточнения координат bounding box

ℒbox = 1 – IoU + ρ²(b,bgt)/c² + α·v
CIoU — Complete Intersection over Union
Параметры обучения

Обучение методом стохастического градиентного спуска с косинусным расписанием скорости обучения:

αt = αmin + ½(α₀ – αmin)(1 + cos(t/T·π))
epochs = 100
batch = 16
imgsz = 640
optimizer = SGD
lr0 = 0.01
momentum = 0.937
conf_thr = 0.25
IoU_nms = 0.45

Применяется transfer learning: предобучение на COCO (80 классов), затем fine-tuning на датасете продукции «Санта Импэкс» (15 классов, 4500+ объектов).

Метрики качества

Качество детекции оценивается метрикой mAP (mean Average Precision):

mAP@0.5 = (1/N) · Σ APi

• IoU = |Bpred ∩ Bgt| / |Bpred ∪ Bgt|

• Precision = TP / (TP + FP)

• Recall = TP / (TP + FN)

F1 = 2 · (P × R) / (P + R)

Требуемая точность: mAP@0.5 ≥ 0.80. Достигнутая: 88–92%

Блок C2f (Cross Stage Partial)

Ключевое улучшение YOLOv8 по сравнению с YOLOv5. Разделяет поток признаков на две ветви для сохранения градиентного потока:

→

→

→

Преимущества перед C3-блоком YOLOv5:

• Более богатый градиентный поток при обратном распространении
• Снижение риска затухания градиентов в глубоких сетях
• Улучшенное извлечение признаков без увеличения числа параметров

Безанкорный (anchor-free) механизм детекции — прямое предсказание смещений относительно центра ячейки сетки, без предопределённых анкеров. Это упрощает конфигурацию модели и повышает точность локализации разноразмерных упаковок (от 70 г эскимо до 450 г контейнера).
